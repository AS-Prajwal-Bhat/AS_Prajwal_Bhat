The major project, block by block

How the SoC fits together

  1. The 5-stage RISC-V core runs the firmware.
  2. An AXI4-Lite bridge and MMIO bus link the core to the accelerators and the UART.
  3. A DCT accelerator transforms 8x8 image blocks and a LeNet-5 CNN classifies the result.
  4. A shared Block RAM holds the data. An image goes in over UART and a class comes out.

Pipelined RISC-V SoC for Edge Vision Intelligence

A 5-stage pipelined RISC-V processor with forwarding, hazard detection and hardware multiply and divide, plus two accelerators on one chip: an 8x8 block DCT for image compression and a LeNet-5 CNN for image classification. It targets the Real Digital Blackboard, a Zynq-7007S board, with a 100 MHz clock.

A Vivado testbench runs the whole path in simulation. It sends a 32x32 image over UART, passes it through the DCT and the CNN, and reads the predicted class back over UART. The CNN uses int8 quantized LeNet-5 weights.
